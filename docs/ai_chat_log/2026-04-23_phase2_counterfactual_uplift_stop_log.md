# 2026-04-23：Phase II 反事实监督改造停线记录

## 背景

本轮尝试将 Phase II 从“PPO + VQ imitation”改为更激进的组合方案：

1. 同一 horizon 上执行全部 archetype，构造反事实收益矩阵  
2. 用 best-code label 进行监督预训练  
3. 按 best-second margin 给监督样本加权  
4. 将 VQ imitation 降为可选弱正则（默认接近关闭）

对应实验批次：`batch_03-short`  
主日志：`logs/AL/batch_03-short/AL_pipeline_20260422_231309.log`

---

## 判定：该方向不再继续

结论：**本方向不作为后续主线，停止继续实验。**

主要原因：

1. **架构侵入过大**  
   不再是参数/训练细节级优化，而是训练目标、数据流、监督协议、日志与 checkpoint 语义的系统性改造。

2. **收益改进不具备“明显压倒性”**  
   尽管训练流程可跑通，但在 val/test 对 DP 的 gap 仍明显，且最终健康度仍是 `weak_edge`。

3. **调参与维护复杂度显著上升**  
   新增监督阶段、反事实矩阵计算、margin 权重机制，带来更多超参与更高运行开销，工程负担明显变重。

4. **与当前主线目标不匹配**  
   当前阶段更需要“低侵入、可解释、可稳定复现”的迭代；本方案偏向大改路径，不符合当前节奏。

---

## 决策与执行口径

1. **即日起停止该方向新增实验。**
2. **该方案仅作为探索记录保留，不作为默认主线策略。**
3. 后续优先回到低侵入优化路径（以现有稳定架构为基础做小步改进）。
